# opendroneid-core-c

`opendroneid.c` and `opendroneid.h` are copied unmodified from
[opendroneid-core-c](https://github.com/opendroneid/opendroneid-core-c),
commit `849c03adbe0cdd68997a462fafab397edcfe53f3` (2026-10-07), under the Apache License 2.0;
see `LICENSE` in this directory.

They encode and decode Open Drone ID (ASTM F3411) messages. chickadeeBRRD
uses the encoder in the firmware and the decoder in its host tests.
